# مساعد الذئب — الحزمة 3 (v0.3.0)

هذه حزمة مصدر لتطبيق Android وخادم وسيط، مصممة كأساس لاستقلال هجين: ذاكرة وسلوك محليان على الهاتف، واتصال اختياري بخادم ذكاء اصطناعي تملكه أو تستضيفه.

## ما الجديد؟
- واجهة محادثة عربية، سجل محفوظ محليًا، وزر لمسح الذاكرة.
- إعداد عنوان خادم HTTPS من داخل التطبيق.
- ردود محلية بسيطة عند عدم ضبط الخادم أو تعذّر الاتصال.
- خادم Node.js يستخدم واجهة متوافقة مع OpenAI Chat Completions، ومفتاح المزود يبقى على الخادم.
- تحقق من المدخلات، حد طلبات أولي، مهلة اتصال، ورسائل خطأ لا تكشف المفتاح.
- اختبارات للخادم وملف Dockerfile.

## ما الذي لا يزال مطلوبًا؟
هذه ليست نسخة متصلة جاهزة بالإنترنت بمجرد التثبيت. يجب نشر `backend/` على استضافة تدعم HTTPS، ثم ضبط متغيرات البيئة السرية لدى الاستضافة. بعد ذلك ضع عنوان الخادم العام في إعدادات التطبيق. لا يوجد مفتاح API مضمّن في الحزمة، ولم يتم شراء أو تفعيل أي خدمة.

## نشر الخادم
1. انشر محتويات مجلد `backend/` في استضافة Node.js تدعم HTTPS أو ابنِ الصورة من `backend/Dockerfile`.
2. اضبط متغيرات البيئة في لوحة الاستضافة:
   - `WOLF_AI_BASE_URL` عنوان API متوافق مع OpenAI وينتهي عادةً بـ `/v1`.
   - `WOLF_AI_API_KEY` المفتاح السري الذي توفره خدمة الذكاء الاصطناعي.
   - `WOLF_AI_MODEL` اسم النموذج المتاح لحسابك.
3. لا تضع المفتاح في التطبيق، أو داخل ملف `.env` مرفوع إلى GitHub، أو في سجل عام.
4. اختبر `https://عنوان-الخادم/health`؛ ينبغي أن تحصل على `{ "ok": true, ... }`.
5. في التطبيق اضغط ⚙، أدخل عنوان الخادم الأساسي فقط مثل `https://wolf-api.example.com` دون `/chat`، ثم احفظ.

يمكنك استخدام مزود متوافق آخر بتغيير `WOLF_AI_BASE_URL` و`WOLF_AI_MODEL` حسب توثيق ذلك المزود. يجب أن يدعم المسار `/chat/completions` وصيغة الاستجابة المتوافقة.

## الاختبارات المحلية للخادم
داخل `backend/`:
```bash
npm install
npm test
npm start
```
من دون `WOLF_AI_API_KEY`، يعيد `/chat` حالة 503 مقصودة، بدلًا من اختلاق رد ذكاء اصطناعي.

## بناء APK باستخدام GitHub Actions
1. فك ضغط الحزمة.
2. ارفع **محتويات** المجلد `wolf-package3` إلى جذر المستودع `abdoabas997-art/wolf-assistant` على الفرع `main`، مع الحفاظ على `.github/` وبقية المسارات.
3. افتح Actions، واختر `Android APK Build`، وشغّل `Run workflow` إذا لم يبدأ البناء تلقائيًا.
4. بعد نجاح التشغيل، افتح صفحة التشغيل ونزّل `wolf-assistant-debug-apk` من قسم Artifacts.

## الخصوصية والحدود
- سجل المحادثة محفوظ محليًا في بيانات التطبيق، ومسح الذاكرة يحذف هذا السجل من التطبيق.
- عند الاتصال بالخادم، تُرسل الرسالة وآخر أجزاء من سجل المحادثة إلى خادمك ثم إلى مزود النموذج.
- لا يتضمن هذا الإصدار تحكمًا فعليًا في التطبيقات الأخرى أو صوتًا أو نموذجًا محليًا كبيرًا. هذه مراحل لاحقة تحتاج إلى تنفيذ واختبار منفصل.
- عنوان الخادم يجب أن يكون HTTPS؛ لا تستخدم HTTP غير المشفر.
- حد الطلبات الحالي في الذاكرة مناسب كنقطة بداية فقط؛ استضف الخادم خلف HTTPS واستخدم حماية/حدود استخدام من مزود الاستضافة قبل الاستخدام العام.
